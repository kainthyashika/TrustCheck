Privacy Policy

Last Updated: October 2026

1. Data Collection & Purpose: TrustCheck operates strictly as a non-intrusive security configuration auditing tool. We collect target domain names, publicly advertised HTTP response headers, TLS certificate details, and public DNS records (A, AAAA, MX, NS, TXT, SPF, DMARC).

2. Credential Redaction: When inspecting HTTP cookie attributes, all session identifiers and token values are redacted using [REDACTED] before persistence in findings records. No plain text session identifiers are retained.

3. Non-Intrusion Policy: TrustCheck does not perform active vulnerability exploitation, SQL injection testing, payload execution, or credential stuffing. All network evaluations strictly use benign HTTP HEAD/GET and standard DNS queries.

4. Data Isolation: Monitored target domains and assessment histories are scoped strictly to the authenticated user account and are not shared with third parties.
